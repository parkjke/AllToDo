# AllToDo Web App

AllToDo 애플리케이션의 웹 버전입니다. Android/iOS 앱과 동일한 지도 기반 경험을 웹 브라우저에서 제공합니다.

## 실행 방법 (How to Run)

터미널에서 `AllToDo-WebApp` 폴더로 이동한 후, 다음 명령어를 실행하세요.

```bash
# 1. 의존성 설치 (최초 1회)
npm install

# 2. 개발 서버 실행
npm run dev
```

### 접속 주소
실행 후 브라우저에서 아래 주소로 접속합니다:
👉 **https://localhost:5175**

---

## 프로젝트 구성 (Stack)
*   **Framework**: React 19 + TypeScript + Vite
*   **Styling**: Tailwind CSS
*   **Map SDK**: react-kakao-maps-sdk
