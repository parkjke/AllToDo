# 🤖 AGENT WORK RULES (에이전트 작업 수칙)

이 문서는 AI 에이전트가 사용자와 협업할 때 반드시 준수해야 할 행동 수칙을 정의합니다.

## 1. 언어 (Language)
- **모든 문서와 알림(Notification)은 반드시 '한국어(Korean)'로 작성합니다.**
- 코드 변경 사항에 대한 설명, 커밋 메시지, PR 본문 등도 한국어를 우선합니다.
- (단, 코드는 영어를 사용합니다.)

## 2. 작업 승인 (Approval Policy)
- **컴파일 에러(Compilation Error)를 수정하는 경우**: 별도의 승인 없이 즉시 수정하고 보고합니다.
- **그 외 모든 작업 (기능 추가, 리팩토링, 최적화 등)**:
    - 반드시 작업 **전에** 사용자에게 계획을 설명하고 진행 여부를 **물어봐야 합니다.**
    - 명시적인 요청이나 승인 없이 코드를 수정하지 않습니다.

## 3. 기억 보존 (Memory)
- 에이전트는 작업 시작 시 항상 이 파일(`docs/AGENT_WORK_RULES.md`)과 `docs/CRITICAL_CODE_LOCKS.md`를 확인하여 사용자의 규칙을 상기해야 합니다.
