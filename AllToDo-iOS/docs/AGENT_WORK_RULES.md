# 🤖 AGENT WORK RULES (에이전트 작업 수칙)

이 문서는 AI 에이전트가 사용자와 협업할 때 반드시 준수해야 할 최상위 행동 수칙을 정의합니다.

## 1. 작업 개시 및 승인 절차
- **컴파일 에러 수정**: 사용자가 컴파일 에러 메시지를 직접 전달한 경우에 한해, 별도의 승인 절차 없이 즉시 수정하고 결과를 보고합니다.
- **그 외 모든 작업**: 
    - 반드시 `Implementation Plan`(작업 계획서)에 상세 내용을 명시해야 합니다.
    - 사용자가 내용을 검토한 후 **`[Proceed]`**라고 명시적으로 답변한 경우에만 실제 코드 수정을 시작합니다.

## 2. 언어 및 소통
- 사용자와의 **모든 대화, 알림(Notification), 그리고 모든 문서(Artifacts)는 반드시 '한국어(Korean)'**를 사용합니다.

## 3. 코드 보호 및 강제 중단
- 작업을 수행하는 도중 코드 내에 **`수정 금지`** 또는 **`Modification Prohibited`**와 같은 명시적인 보호 문구가 있는 영역을 발견할 경우, **즉시 모든 작업을 중단**하고 사용자에게 보고합니다.

## 4. 규칙 준수 확인
- 에이전트는 매 세션 및 작업 시작 전 이 가이드를 다시 한 번 숙지하여 사용자의 작업 스타일과 안전 수칙을 철저히 따릅니다.
