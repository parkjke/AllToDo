# Porting Guide: Map Consistency (Google/Naver/Kakao)

Apply the following changes to match the finalized Apple Map behavior.

## 1. Pin Logic (Main Map)

### A. Asset Usage
*   **Asset**: Always use `PinHistory` image (`UIImage(named: "PinHistory")`) for history items.
*   **Fallback**: Only if asset fails, use `PinImageHelper`.
*   **Result**: It should look like an **Empty Red Shield** (the user's asset).

### B. Cluster Logic (Priority)
Ensure custom cluster rendering follows this priority for the **Icon**:
1.  **Priority 1**: `UserLocation` (If cluster contains current location).
2.  **Priority 2**: `History` (If history count > todo count).
3.  **Priority 3**: `Todo` (Default).

*Note: Badge count should still be total count.*

## 2. Path View Logic (`PathHistoryView`)

### A. Pin Style
*   **Image**: `PinHistory` (Red Shield).
*   **Label**: Add a `UILabel` (or text overlay) on top of the pin.
*   **Default State**: `label.text = ""` (Hidden by default).
*   **Debug Capability**: Code must exist to set `label.text = annotation.title` easily for debugging.

### B. Zoom Clamp
When fitting bounds for the path:
*   **Min Span**: `0.003` (Approx Zoom Level 17).
*   **Formula**: `max(delta * 1.5, 0.003)`
*   *Do not zoom in closer than Level 17, even for 1-meter paths.*

## 3. Launch Animation (Re-entry)

### A. Configuration
*   **Delay**: Use `AppConfig.launchAnimationDelay`.
    *   `DEBUG`: **3.0s**
    *   `RELEASE`: **1.0s**
*   **Threshold**: Use `AppConfig.backgroundReentryThreshold`.
    *   `DEBUG`: **5s**
    *   `RELEASE`: **9m**

### B. Logic (In `ContentView` or MapView)
*   **Short Absence (<= Threshold)**: Do NOT run animation. Keep current state.
*   **Long Absence (> Threshold)**: Run Launch Animation (Zoom 17 -> User).
