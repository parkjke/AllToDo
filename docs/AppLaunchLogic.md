# 앱 시작 시퀀스 (App Launch Logic)

## 1. 개요
사용자가 앱을 처음 실행했을 때, 지도와 핀을 보여주는 초기화 과정(Launch Animation)을 정의한 문서입니다. 사용자가 자신의 할 일 전체를 조망하고, 자연스럽게 현재 위치로 집중할 수 있도록 "감성적인 시퀀스"를 적용했습니다.

## 2. 시퀀스 단계 (The Sequence)

### Step 1: 전체 뷰 (Whole View) - [즉시 실행]
- 앱이 켜지자마자 내 주변(500km 이내)의 모든 핀/경로가 한 화면에 들어오도록 줌을 맞춥니다.
- **핵심 기술**:
  - **500km 필터링 적용**: 미국 등 너무 먼 핀은 bounds 계산에서 제외하여, 태평양 뷰가 나오는 것을 방지합니다.
  - **최대 줌 제한**: 핀이 하나밖에 없거나 너무 가까이 몰려 있어 구글/네이버 지도가 자동으로 20레벨까지 확대하려 할 때, **최소 15레벨**까지만 확대되도록(너무 가까워지는 것을 방지) 제한합니다. (if zoom > 15 then zoom = 15)

### Step 2: 감상 대기 (Wait) - [3초]
- 사용자가 전체적인 할 일 분포를 눈으로 확인할 수 있도록 **3초간 화면을 유지**합니다.
- 이때 500km 밖에 핀이 있다면, 상단에 **"N개의 할 일이 멀리 있습니다"** 라는 알림창(Toast)이 뜬 후 사라집니다.

### Step 3: 현재 위치 집중 (Zoom to Current) - [자동 이동]
- 3초 후, 카메라가 부드럽게 **현재 사용자 위치(Current Location)**로 이동하며 확대됩니다.
- **목표 줌 레벨**: **17.0** (기존 18.0에서 조정됨. 적절한 거리감 유지).

## 3. 예외 처리 (Fallback)
- **핀이 하나도 없는 경우**: Step 1을 생략하고 즉시 현재 위치로 부드럽게 이동합니다. (초기 줌 15)
- **현재 위치를 못 잡은 경우**: 마지막으로 저장된 위치 혹은 기본 위치(서울시청)에서 대기하며, 위치가 잡히는 즉시 Step 3 애니메이션을 수행합니다.

## 4. 구현 파일
- **Android**: `GoogleMapContent.kt`, `NaverMapContent.kt`, `KakaoMapContent.kt` 내 `LaunchedEffect(isMapReady)` 블록.
- **iOS**: `AppleMapView.swift` 내 `performLaunchAnimation()` 함수.
