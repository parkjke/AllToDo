# 맵 클러스터링 및 로직 개선 워크쓰루

이 문서는 AllToDo 앱의 Android 및 iOS 플랫폼 전반에 걸쳐 맵 클러스터링, 초기 실행 시퀀스, 데이터 필터링 로직을 일관성 있게 개선한 내용을 상세히 기술합니다.

## 1. 핵심 로직 개선 (크로스 플랫폼)

### 클러스터링 전략
- **기준 변경**: 기존 줌 레벨(Zoom-Level) 기반에서 **화면 가로폭 거리(ScreenWidthMeters, Wm)** 기반으로 변경했습니다.
- **임계값 도입**: **1.5배 변화 임계값**을 적용했습니다. `현재 Wm / 마지막 클러스터링 Wm` 비율이 `[0.66, 1.5]` 범위를 벗어날 때만 재클러스터링을 수행합니다.
- **트리거 최적화**: 맵 이동/줌 중에는 클러스터링을 중단하고, **Map Idle(Android)** 또는 **Region Change End(iOS)** 시점에만 엄격하게 수행하여 성능을 최적화했습니다.
- **WASM 안정성**: `lib.rs`에 위경도 기반의 결정론적 정렬(Deterministic Sorting) 로직을 추가하여, 입력 순서에 따른 클러스터링 결과 변화(깜빡임)를 제거했습니다.

### 데이터 필터링 및 단일 진실 공급원(SSOT)
- **시간 범위**: 기준 날짜(또는 현재 시간)로부터 `+/- 24시간` 데이터를 쿼리합니다.
- **경로 유효성**: `no_of_path > 0`인 항목만 엄격하게 필터링합니다.
- **지리적 분할**: 한국 내(`isInKorea`) 여부를 판단하는 로직을 양대 플랫폼 모두 정수 좌표계(1e5 scale)로 통일했습니다.

## 2. Android 구현

### `MapFeatureViewModel.kt`
- **초기 시퀀스 정립**:
  1. 줌 레벨 15로 맵 로드.
  2. `ZOOM_TO_FIT`: 모든 핀(사용자 + 할 일)을 포함하도록 바운드 조정.
  3. **3초 대기**: 클러스터링되지 않은 원본 핀(Raw Pins) 노출.
  4. 3초 후 사용자 위치로 이동(줌 18) 및 클러스터링 활성화.
- **데이터 리프레시**: 5초 이상 백그라운드 체류 후 복귀 시 데이터를 즉시 갱신하도록 `updateFilteredItems(immediate=true)`를 공개했습니다.

### 맵 컴포넌트
- **Idle 감지**: `GoogleMapContent`, `NaverMapContent`, `KakaoMapContent`가 `onCameraIdle` 발생 시 현재 `latLngBounds`를 ViewModel에 정확히 보고하도록 수정했습니다.

## 3. iOS 구현

### 맵 뷰 (`Kakao`, `Naver`, `Apple`)
- **Wm 계산**: `refreshWasmClusters` 내에서 `metersPerPixel * mapWidth`를 계산하여 클러스터링 반경을 동적으로 결정합니다.
- **최적화**:
  - `force` 파라미터를 추가하여 데이터 변경 시에는 1.5배 임계값을 무시하고 즉시 갱신하도록 했습니다.
  - **Kakao**: `cameraDidStopped` 델리게이트에서 클러스터링이 정상적으로 트리거되도록 수정했습니다.
  - **Apple**: 클러스터링 트리거를 `mapViewDidChangeVisibleRegion`(지속 호출)에서 `regionDidChangeAnimated`(Idle)로 이동했습니다.
  - **Naver**: 초기 실행 시퀀스에서 강제 리프레시(`force: true`)를 적용했습니다.

### `MapLogicHelper.swift`
- **동기화**: `isInKorea` 로직을 Android와 동일하게 100,000 스케일 팩터를 사용하는 정수 좌표계 로직으로 변경했습니다.

## 4. 검증 가이드

### 초기 실행 (Cold Start)
1. 앱을 실행합니다.
2. **관찰**: 맵이 로드되면서 모든 핀이 클러스터링되지 않은 상태로 보이고, 전체 영역이 한눈에 들어옵니다.
3. **대기**: 3초 후 맵이 현재 위치로 줌인(레벨 18)되면서 애니메이션이 동작합니다.
4. **결과**: 줌인 완료 후 핀들이 적절히 클러스터링됩니다.

### 맵 이동/줌 (Panning/Zooming)
1. 맵을 조금씩 이동해봅니다.
2. **관찰**: 드래그 중에는 클러스터가 변하지 않아야 합니다.
3. 손을 뗍니다(Idle).
4. **관찰**: 줌이나 이동 범위가 크지 않다면(1.5배 임계값 이내), 클러스터링이 다시 계산되지 않고 유지됩니다. 크게 이동했을 때만 갱신됩니다.

### 백그라운드/포그라운드 전환
1. 앱을 5초 이상 백그라운드로 보냅니다.
2. 다시 앱을 엽니다.
3. **관찰**: 데이터가 새로고침되며(필요 시 로딩 표시), `+/- 24시간` 기준에 맞는 유효한 아이템만 맵에 표시됩니다.
