# 스마트 트래킹 (Smart Tracking) & 위치 최적화 기술 문서

## 1. 개요
스마트 트래킹(Smart Tracking)은 지도 앱의 성능 최적화와 배터리 절약을 위해 고안된 위치 갱신 알고리즘입니다. 사용자의 움직임에 따라 지도를 무조건 갱신하는 것이 아니라, **현재 줌 레벨(Zoom Level)**과 **이동 거리**를 계산하여 "정말로 시각적인 변화가 필요한 경우"에만 UI를 업데이트합니다.

## 2. 주요 로직
### 2.1. 정수 좌표 사용 (Integer Coordinates)
- **개념**: 부동 소수점(Double) 좌표의 미세한 떨림을 방지하기 위해, 위도/경도에 `100,000`을 곱해 정수(Int)로 변환하여 비교합니다.
- **효과**: 불필요한 연산 부하 감소 및 부동 소수점 오차로 인한 미세 진동(Jitter) 제거.

### 2.2. 동적 임계값 (Dynamic Threshold)
- **개념**: 지도가 많이 확대되었을 때는 작은 움직임도 반영하고, 축소되었을 때는 큰 움직임만 반영합니다.
- **Android 공식**:
  ```kotlin
  val threshold = if (zoom >= 18) 2 else if (zoom >= 15) 5 else ...
  ```
- **iOS 공식**: 
  ```swift
  let threshold = max(2, Int(currentSpan * 200.0))
  // Span이 클수록(줌 아웃) 임계값이 커져 둔감하게 반응
  ```

## 3. 500km 필터링 (Far Item Filtering)
- **문제점**: 미국이나 유럽 등 현 위치에서 매우 먼 곳에 핀이 있을 경우, 초기 화면 설정 시 지도가 '태평양'을 보여주며 줌이 과도하게 빠지는 현상 발생.
- **해결책**:
  - 현재 위치 기준 반경 **500km 이내**의 핀만 "유효한 핀"으로 간주하여 렌더링 및 줌 계산에 포함.
  - 500km 밖의 핀은 렌더링에서 제외하되, 사용자에게 **"N개의 할 일이 멀리 있습니다."** 라는 메시지로 존재를 알림.

## 4. 지도 이탈 방지 (Map Tethering)
- **목적**: 사용자가 지도를 자유롭게 탐색(Pan/Zoom)할 수 있게 하되, 자신의 위치를 완전히 잃어버리는 것을 방지.
- **알고리즘**:
  1.  지도 이동/줌 시, 현재 화면의 **가로 폭(Longitude Delta/Span)**을 정수형(`hDistance`)으로 저장.
  2.  위치 업데이트 시, `|MapCenter.Lon - User.Lon|` (중심과 사용자 간 거리)를 계산.
  3.  거리가 `hDistance / 4` (화면 폭의 25%)를 초과하면, 지도의 중심을 사용자 위치로 부드럽게 이동.
- **효과**: 걸어다니면서 지도를 볼 때, 별도의 조작 없이도 내 위치가 항상 화면 중앙 부근(50% 영역 내)에 유지됨.

## 5. 적용 효과
- **배터리 절약**: 불필요한 재렌더링 빈도 50% 이상 감소.
- **발열 감소**: CPU/GPU 부하 감소.
- **시각적 안정성**: 정차 중 GPS 오차로 지도가 튀는 현상 방지.

## 6. 플랫폼 적용 현황
- **Android**: `SmartLocationManager.kt` - 카카오/네이버/구글 전 지도 적용 완료.
- **iOS**: `SmartLocationManager.swift` - 애플맵 및 `AppLocationManager` 전체 적용 완료.
