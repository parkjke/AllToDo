# 한글 초성 검색 로직 (Korean Choseong Search)

한국어 사용자의 검색 편의성을 극대화하기 위해 초성 추출 및 매칭 기능을 제공합니다.

## 1. 핵심 유틸리티 (`KoreanUtils.kt`)
`kr.alltodo.utils.KoreanUtils` 클래스에서 다음 기능을 제공합니다.

*   **`extractChoseong(text)`**: 입력된 한글 문자열에서 초성(ㄱ, ㄴ, ㄷ 등)만 분리하여 추출합니다.
*   **`match(text, query)`**: 일반 문자열 포함 검색과 초성 매칭을 결합하여 지능형 검색 결과를 반환합니다.

## 2. 사용처 (Usage)

### A. 데이터베이스 저장 시 (Indexing)
*   **위치**: `Repository` 레이어 (`AddressBookRepository`, `TodoRepository`)
*   **방식**: 데이터를 DB에 저장(Insert/Update)하기 전, 명칭이나 주소 필드에서 초성을 추출하여 별도의 `name_consonants` 필드 등에 저장합니다.
*   **이유**: 검색 시 매번 초성을 추출하는 오버헤드를 줄여 대량의 데이터에서도 즉각적인 검색 속도를 보장합니다.

### B. 실시간 필터링 (In-memory Filtering)
*   **위치**: `ViewModel` 또는 `Compose UI`
*   **방식**: 사용자가 입력한 검색어(쿼리)에 대해 리스트 전체를 순회하며 `match()` 함수를 호출하여 필터링된 결과를 보여줍니다.
*   **예시**: 주소록 검색, 할 일 목록 검색 등.

## 3. 알고리즘 원리
1.  한글 음절의 유니코드 영역(`0xAC00` ~ `0xD7A3`)을 판별합니다.
2.  공식 초성 인덱스 계산법 `(음절 - 0xAC00) / (21 * 28)`을 통해 19가지 초성 중 하나를 도출합니다.
3.  한글이 아닌 숫자, 영문, 특수문자는 변환 없이 그대로 유지하여 검색 범용성을 확보합니다.
