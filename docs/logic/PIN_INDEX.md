# AllToDo Pin Index Specification (핀 번호 통합 명세서)

본 문서는 AllToDo 앱에서 사용하는 모든 핀 번호(Type ID)의 시각적 정의와 기능적 의미를 통합하여 관리하는 공식 문서입니다.

## 1. 핀 생성 체계 (Type System)
핀 ID는 두 자리 숫자로 구성되며, 각 자릿수는 다음을 의미합니다.
- **앞자리 (Tens Place)**: 배경색 (Shield Category)
    - `0`: **빨강 (Red)** - 위치, 자취, 북마크
    - `1`: **녹색 (Green)** - 사용자가 만든 할 일 (Local Todo)
    - `2`: **파랑 (Blue)** - 서버 연동 할 일 (Server/System Todo)
- **뒷자리 (Ones Place)**: 내부 마크 (Mark/Icon)

## 3. 관리 지침
- **에셋 확인**: 표 안의 이미지는 가독성을 위해 미리 **32px(텍스트 2배 크기)**로 조정된 전용 에셋(`pins_small/`)을 사용합니다.
- **신규 추가**: 새로운 마크 추가 시 `Icons/map_pin_1/mark/`에 SVG를 생성하고 본 문서에 이미지를 등록해야 합니다.
- **최종 빌드**: `generate_static_assets.py`를 실행하여 실제 모바일용 비트맵(120x150px)을 생산합니다.
