## 2. 상세 설명

### 2.1. 핀 디자인 표준화 (Pin Design Standardization)
- 모든 지도에서 **"동그라미 핀 + 우측 상단 숫자 배지"** 스타일로 통일되었습니다.
- **색상 규칙**:
  - **초록색 (Green)**: 로컬 할 일 (Local Todo) - **클러스터 최우선 순위 (v1.3)**
  - **파란색 (Blue)**: 서버 수신 할 일 (Server Todo)
  - **빨간색 (Red)**: 현재 위치, 이동 경로(History)

### 2.2. 스마트 트래킹 & 500km 필터링
- 모든 플랫폼에서 사용자 위치 갱신 빈도를 최적화하여 배터리를 절약합니다.
- 모든 지도에서 현 위치 기준 **500km** 밖의 핀은 렌더링하지 않으며, **"N개의 할 일이 멀리 있습니다"** 라는 메시지로 알려줍니다.

### 2.3. 나침반 버그 수정 (Compass Fix)
- 안드로이드 구글/네이버 지도에서 나침반 버튼 클릭 시 지도가 서울시청(기본값)으로 초기화되는 버그를 수정했습니다.
- 이제 나침반을 누르면 **"현재 지도 중심을 유지한 채"** 북쪽으로 회전만 수행합니다.

### 2.4. 히스토리 통합 및 컨텍스트 기반 할 일 생성
- 히스토리 기록이 레거시 테이블(`UserLog`)에서 `TodoItem` 테이블로 통합되었습니다. (타입 `"00"`)
- 물풍선(Callout)의 날짜/시간 영역을 클릭하면 해당 위치와 이름을 기반으로 즉시 할 일을 생성/복사할 수 있습니다.
- **동적 타이틀**: 새로 생성 시 **"할 일 만들기"**, 기존 핀 기반 생성 시 **"할 일"**로 타이틀이 자동 전환됩니다.

## 3. 최근 수정 사항 (Recent Fixes)

### 3.1. [해결됨] iOS - Kakao Map 현재 위치 핀 누락 및 이동성 확보
- **수정**: 클러스터링 로직에서 사용자 위치(`.userLocation`)를 아이템 리스트에 강제 포함시켜, 카카오 맵에서도 내 위치가 정상적으로 표시되도록 수정 완료.

### 3.2. [해결됨] 지도 엔진별 줌 레벨 정합성 (Zoom 18 Standard)
- **안드로이드 네이버 맵**: 시작 시퀀스에서 설정된 `maxZoom` 제한이 해제되지 않던 버그를 수정하여, [현재 위치] 클릭 시 정상적으로 줌 18까지 확대되도록 보정.
- **iOS 애플 맵**: 기존 `0.0025` span이 타 지도 대비 다소 멀게 보이던 현상을 **`0.0013`**으로 정밀 조정하여 시각적 정합성 100% 확보.

### 3.3. [신규] 내 위치 중심 클러스터 앵커링 (Cluster-at-User)
- **기능**: 클러스터 내부에 '현재 위치'가 포함된 경우, 핀의 렌더링 좌표를 기하학적 중앙값이 아닌 **실제 사용자 좌표**에 고정(Anchoring).
- **효과**: 클러스터링으로 인해 내 위치가 핀 뭉치 중앙으로 밀려나 실제 위치를 벗어나는 '위치 이탈(Drift)' 현상을 원천 방지하며, 이동 중에도 핀이 나를 정확히 따라오는 유기적인 UX를 제공함.
