# 🔍 지도 검색 기능 (Map Search System)

지도 상에서 장소(POI)를 검색하고 결과를 확인하는 기능의 시각적 규격과 로직을 정의합니다.

---

## 🚀 1. 핵심 컴포넌트 (Components)

### A. 검색 버튼 (`SearchButton`)
- **디자인**: `Circle` 배경에 `magnifyingglass` 아이콘이 포함된 플로팅 버튼.
- **위치 (iOS)**: 화면 하단 **Safe Area로부터 16pt 상단**에 고정. (조작 편의성과 시각적 안정감 확보)
- **인터랙션**: 클릭 시 `SearchOverlay`를 활성화(`isOverlayVisible = true`).

### B. 검색 레이어 (`SearchOverlay`)
- **구조**: 상단 검색바 + 하단 결과 리스트 (또는 최근 검색어).
- **디자인**: 
    - 배경: Pure White (#FFFFFF) 및 RoundedCorner (상단 24dp).
    - 테마: **지도 엔진 정책**에 따라 라이트/다크 모드 결정.

---

## ⚙️ 2. 검색 및 데이터 로직 (Search Logic)

### A. 데이터 제공자 (Providers)
- **핵심 API**: 카카오 로컬(Kakao Local) 키워드 검색 API 연동.
- **통합 검색**: `SearchViewModel`을 통해 iOS와 Android의 검색 요청 및 결과 처리 로직을 단일화.

### B. 결과 최적화 (UX Polish)
- **거리 단위 자동 변환**:
    - 1,000m 미만: `m` 단위로 표시 (예: `450m`).
    - 1,000m 이상: `km` 단위로 소수점 첫째 자리까지 표시 (예: `1.2km`).
- **한글 초성 검색**: `KoreanUtils`를 활용하여 초성(ㄱㄴㄷ)만으로도 지능형 매칭 지원.

---

## 🎨 3. 안드로이드 전용 최적화 (Android Polish)

안드로이드 검색바의 가독성과 한글 입력 안정성을 위해 다음 특수 로직이 적용되어 있습니다.

- **커서 색상 (Cursor Color)**: 테마에 감응하여 다크 모드에서도 시인성 확보.
- **입력 밑줄 제거**: 한글 입력 중 발생하는 시스템 기본 밑줄을 `VisualTransformation.None` 또는 투명 처리를 통해 제거하여 디자인 일관성 유지.
- **조작계 직관성**: 검색 결과 리스트의 텍스트를 굵게(Bold) 처리하고, 리스트 간 간격을 넓혀 터치 정확도 향상.

---

## 🌓 4. 테마 정책 (Theme Policy)

지도의 가독성을 위해 검색창 및 관련 UI는 하단 지도 엔진의 특성에 맞게 동적으로 조정됩니다.

| 지도 엔진 | 테마 정책 | 비고 |
| :--- | :--- | :--- |
| **Apple / Google** | 시스템 테마 감응 | 시스템 설정(라이트/다크)을 따름 |
| **Naver / Kakao** | **라이트 모드 고정** | 지도가 라이트 모드로 강제되므로 UI도 화이트로 고정 |

---

## 🎯 5. 결과 선택 시 동작 (Interaction)

1.  **카메라 이동**: 검색 결과 선택 시, 해당 장소의 위경도 좌표로 지도의 중심이 즉시 이동합니다.
2.  **줌 레벨**: 고해상도 확인을 위해 **줌 레벨 18.0** 수준으로 확대 이동합니다.
3.  **오버레이 종료**: 이동과 동시에 검색 레이어가 닫히며 지도가 전면에 나타납니다.
